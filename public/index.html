HeySalad Selena is live as a launch-ready blueprint.

Record it yourself or send Selena.

Selena is a HeySalad screen recording agent for walkthroughs, decks, and product demos. The fast path is a split system: humans start local browser capture, while AI runs recordings inside remote browsers and desktops that Selena controls.

Human Mode

Use Selena like Loom. The user clicks record, selects a screen, and uploads the capture directly to cloud video storage.

  • Best first launch
  • No browser extension required for MVP
  • Fits pitch decks and app walkthroughs today

Agent Mode

Send Selena to run a walkthrough in a remote browser first, then expand to remote desktop for native apps and full desktop demos.

  • Browser automation ships before desktop automation
  • Remote execution avoids local permission blockers
  • Ideal for repeatable product tours

Fastest Route Online

Ship the browser recorder first, then add Selena-run browser sessions. Only build full remote desktop capture once those two lanes are stable.

  • Worker API + landing page now
  • Cloudflare Stream next
  • Remote desktop after browser traction
